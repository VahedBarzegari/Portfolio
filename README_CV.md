## To Convert to PDF:

### Option 1: Using Your Browser (Recommended)
1. Open `Vahed_Barzegari_CV.html` in any web browser (Chrome, Safari, Firefox, etc.)
2. Press `Cmd+P` (Mac) or `Ctrl+P` (Windows/Linux) to open the print dialog
3. Select "Save as PDF" or "Print to PDF" as the destination
4. Make sure the following print settings are selected:
   - Paper size: Letter (8.5" x 11")
   - Margins: Default or Minimum
   - Background graphics: Enabled (to show colors)
   - Scale: 100%
5. Click "Save" and choose a location for your PDF file

### Option 2: Using Python (if reportlab is installed)
If you have reportlab installed, you can run:
```bash

```

This will generate `Vahed_Barzegari_CV.pdf` directly.
